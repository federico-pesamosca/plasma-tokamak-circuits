# Reduced vertical RZIp model

From the project root in an existing MATLAB session with IMAS available:

```matlab
add_plasmaless_paths
run_vertical_instability
runtests('tests/test_vertical_instability.m')
```

The runner plots a 0.01 V step on the active coil with the largest input projection onto the unstable mode. It shows `zIp`, active-current perturbations and passive-current perturbations until the vertical displacement first reaches approximately 5 cm, then calls `plot_vertical_instability` for the response histories and an ITER cross-section animation. `run_vertical_instability_model` remains a compatibility entry point. These are deviations from the equilibrium, not absolute currents or absolute plasma height.

## Configuration and outputs

```matlab
[model,x0] = configure_vertical_instability_model(0.001);
% Or supply data explicitly:
eq = extract_equilibrium_data(uri,time);
[em,pa,pe] = load_plasmaless_md();
[model,x0] = configure_vertical_instability_model(0.001,eq,em,pa,pe);
```

`model.A/B/C/D`, `sysd`, `dt`, `M`, `R`, `coil_names`, `loop_names`, `n_coils` and `n_loops` follow the existing plasmaless configuration structure. `M` is the reduced effective inductance. The continuous model is available as `sys` and `Ac/Bc/Cc/Dc`; `M11/M12/M21/M22` expose the descriptor blocks. Discretization is exact zero-order hold.

The reduced state is `x = [delta_Ia; delta_Ie]`, input is `Va`, and output order is `[zIp; delta_Ia; delta_Ie]`. `zIp = Ip0 * delta_z`; use `zIp/model.Ip0` for displacement in metres. `x0` is a zero perturbation. `Ic0` stores the equilibrium conductor currents separately.

## Equations

Let `q = Ip0 * delta_z`, `I = [delta_Ia;delta_Ie]`, and `S = [eye(n_coils);zeros(n_loops,n_coils)]`. With total plasma current fixed and radial motion excluded:

```text
M11 * dI/dt + M12 * dq/dt + R * I = S * Va
M21 * I + M22 * q = 0
```

For equilibrium filament currents `J` and their rigid-displacement derivative `dJdzC = -dJ/dz` (including grid area weights), conductor-to-grid full-flux map `Mxi`, and radial-field map `dBrxdIc`:

```text
M11 = [Maa Mea'; Mea Mee]
M12 = (dJdzC' * Mxi)' / Ip0
M21 = -2*pi * (R_grid .* J)' * dBrxdIc / Ip0
M22 = -2*pi * sum(R_grid .* dJdzC .* Br_external) / Ip0^2
Br_external = dBrxdIc * Ic0
```

The formulation of `M11`, `M12`, `M21` and `M22` follows:
- A. Coutlis et al., Nucl. Fusion 39 (1999).
- F. Pesamosca, PhD thesis, EPFL (2021) - see Appendix B.

`M21` uses the direct Lorentz-force expression. `M12` uses the derivative of the flux linkage. They coincide in the continuum rigid-displacement limit through integration by parts; the implementation retains their separately discretized forms.

Singular perturbation imposes instantaneous vertical force balance:

```text
Czr  = -M21 / M22
Meff = M11 - M12 * (M21 / M22)
Ac   = -(Meff \ R)
Bc   = Meff \ S
Cc   = [Czr; eye(n_coils+n_loops)]
Dc   = zeros(1+n_coils+n_loops,n_coils)
```

There is no direct voltage feedthrough to displacement: it is reconstructed from the current states. No radial-force or plasma-current equation is included.

## Data handling

The default equilibrium is ITER entry `105108/2` at `100 s`, as specified in the original extractor. The DD4 conductor matrices and flux maps come from `load_plasmaless_md`. Full-flux maps use `Br = -dpsi/dz/(2*pi*R)`, and are interpolated onto the equilibrium mesh. Only the vacuum field generated by equilibrium conductor currents enters the force-balance stiffness; plasma self-field is excluded.

When the equilibrium has no `profiles_2d.j_phi`, the extractor reconstructs the distribution from its Grad–Shafranov pressure and current-function profiles:

```text
Jphi = orientation * 2*pi * (R * dp/dpsi + F*dF/dpsi / (mu0*R))
```

The orientation is inferred from the signed stored plasma current after checking the integrated magnitude. Density outside the LCFS is excluded. The configured density is normalized to the supplied `Ip0` only after its integral agrees within 5%; unsupported profiles, truncated plasma support, or inadequate flux-map coverage cause an error. The default entry's correction is approximately 0.999908. The extractor returns `RR`, `ZZ`, `Ip0`, `Jtor`, `boundary`, `pf_active` and `pf_passive` for configuration, plus `psi0` and `psix` for plotting; total magnetic-field arrays and unused metadata are omitted.

DINA coil names `VSU/VSL` are explicitly mapped to machine-description names `VS3U/VS3L`; other conductor names and ordering are checked by the existing plasmaless configurator. Supplying `eq.Ic0` in machine-description order bypasses loading/matching the equilibrium current IDSs.

The tests check the real equilibrium for one unstable continuous pole and one discrete pole outside the unit circle. An independent two-circuit fixture checks a growing voltage-step response, instantaneous force balance, current outputs and zero feedthrough. No matrix sign or eigenvalue is modified to force instability.

## Flux and LCFS animation

```matlab
[figures,animation] = plot_vertical_instability(model,time,Va,y,equilibrium);
% A shorter animation:
[figures,animation] = plot_vertical_instability(model,time,Va,y,equilibrium,20);
```

The second figure colors active-coil elements and passive filaments by their current perturbations with fixed, symmetric blue–white–red scales. Active and passive groups use separate limits at half their respective peak amplitudes; larger values saturate. Active-coil colours use signed square-root intensity to make smaller changes visible. The passive-current colourbar remains linear in amperes. All active coils are included, including the annular VS conductors. The first wall and divertor outlines remain fixed.

The extractor uses `psi0 = -profiles_2d.psi'` and `psix = -boundary.psi`, as required to match the machine-description full-flux convention. Plot initialization checks the sign against the signed plasma current through Ampere's law, and checks the boundary flux against the stored LCFS outline. The animation includes all 14 active and 102 passive current perturbations through `reshape(Mxi*delta_Ic,size(psi0))`. It also includes the moving plasma contribution described below. It restricts contours to the common domain of the equilibrium and conductor-map meshes without extrapolating beyond the stored maps.

The local `recompute_xpoint_flux` routine finds a stationary point of a spline interpolant using Newton iterations, checks that the Hessian determinant is negative, and tracks that saddle from frame to frame. Its updated flux defines the separatrix contour; the initial LCFS is drawn as a dashed contour of the unperturbed flux at its recomputed saddle flux. The background flux uses 10 levels. `animation` contains frame times, X-point positions, X-point fluxes, gradient residuals and Hessian determinants. On the current grid the initial recomputed X-point flux is approximately -40.0346 Wb, compared with -40.2198 Wb stored in the IDS; the plotted initial reference uses the recomputed value consistently with the evolving separatrix.

For consistent first-order rigid vertical movement, isolate the equilibrium plasma self-flux by subtracting the vacuum conductor flux:

```text
psi_p0 = psi0 - reshape(Mxi*Ic0,size(psi0))
delta_J = -delta_z * dJ/dZ
delta_psi_p = -delta_z * dpsi_p0/dZ
psi = psi0 + reshape(Mxi*delta_Ic,size(psi0)) + delta_psi_p
```

Vertical translation of the axisymmetric current distribution translates its flux, so the derivative term includes the rigid plasma response without constructing a large grid-to-grid mutual-inductance matrix. This uses the assumption that the baseline total flux consists of the plasma contribution plus the represented conductor currents. It remains a first-order approximation, not a nonlinear Grad–Shafranov solution.

Coil names are omitted from the plots. A growing centroid trajectory and zoomed inset show the displacement in metres. The run retains the 0.01 V step and extends its duration until the first sample reaching 5 cm; for the default equilibrium it reaches 0.050107 m at 2.795 s. This larger displacement deliberately trades some linearization validity for clearer visualization.
